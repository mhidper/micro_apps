📐 Anatomía Matemática del Modelo de Blanchard (Cap. 6)
1. Ecuación de Fisher (Tipo Real): r = i - πᵉ = 2.00% - 2.00% = 0.00%
2. Coste del Crédito para Empresas: r + x = 0.00% + 2.00% = 2.00%
3. Función de Inversión Ampliada: I = 150 + 0,10·Y - 25·(r + x) = 190.0
4. Multiplicador Keynesiano Ampliado (α): α = 1 / (1 - c₁ - d₁) = 1 / (1 - 0.60 - 0.10) = 3.33
5. Producción de Equilibrio (Y*): Y* = α · [c₀ - c₁T + d₀ + G - d₂(r+x)] = 1.000.0
